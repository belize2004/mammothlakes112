# BRANDING-DNA.md

## Purpose

This file defines the brand-design logic for a website before layout, components, or code are created.

The goal is to prevent generic website design.

A strong website should not begin with:

* colors
* fonts
* buttons
* cards
* templates

It should begin with the brand's underlying DNA.

The website must translate that DNA into:

* visual hierarchy
* typography
* spacing
* imagery
* motion
* layout
* interaction
* navigation
* CTAs
* component behavior
* content structure

This document should be completed for every new website project.

## CTA Rules

1. One visually dominant action per decision context.
2. CTA language should describe the next outcome.
3. Brand personality decreases as transaction intent increases.
4. Trust should sit close to high-commitment actions.
5. Repeat CTAs when context changes, not merely because the page is long.
6. Avoid universal "Book Now," "Learn More," or "Submit" buttons when more precise language exists.

# 24. FINAL DESIGN TEST

Before approving any page, ask:

### Distinctiveness

If the logo were removed, would the website still feel like this brand?

### Consistency

Does the page follow the same visual grammar as the rest of the site?

### Restraint

Can anything be removed without hurting usability or communication?

### Recognition

Are the primary brand codes visible?

### Hierarchy

Is it immediately obvious what matters most?

### Conversion

Is there one clear next action?

### Brand Tension

Does the design maintain the intended opposing qualities?

### Originality

Does this look designed specifically for this company, or could the company name be swapped with a competitor?

If the answer to the last question is yes, the design is too generic.

---

# 25. AI DESIGN INSTRUCTION

When this file is supplied to an AI design or coding system:

> Treat this Brand DNA document as a higher-level source of truth than individual component styling. Do not imitate reference websites literally. Use references only to understand principles such as hierarchy, interaction, spacing, storytelling, conversion behavior, or information architecture.

> Every new page and component must be generated from the Brand Truth, Core Idea, Brand Tensions, Recognition Codes, Visual Grammar, CTA DNA, and Brand World defined in this file.

> If a proposed design conflicts with the Brand DNA, the Brand DNA wins.

> Do not fall back to generic website patterns merely because they are common.

> The goal is not consistency through repetition. The goal is recognizable variation generated from a small number of strong rules.
